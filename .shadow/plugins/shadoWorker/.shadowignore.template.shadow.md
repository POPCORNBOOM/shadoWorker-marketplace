# .shadowignore.template.shadow.md

Template for .shadowignore file with default ignore patterns.

Ignores:
- Build outputs: build/, dist/, out/, *.min.js, *.min.css
- Dependencies: node_modules/, vendor/, packages/
- Temporary files: *.tmp, *.log, *.swp, *~
- Environment: .env, .env.local, .env.*.local
- IDE: .vscode/, .idea/, *.sublime-*
- OS: .DS_Store, Thumbs.db
- Test coverage: coverage/, .nyc_output/

Users copy to project root as .shadowignore and add project-specific patterns.
